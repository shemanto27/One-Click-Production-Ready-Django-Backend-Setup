# Configuration

## Environment Variables

The generated project uses environment variables for configuration. These are stored in `backend/.env`.

### Django Settings

```bash
SECRET_KEY=<auto-generated>
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1

DATABASE_URL=postgresql://user:password@localhost:5432/dbname
```

### Superuser Credentials

```bash
DJANGO_SUPERUSER_USERNAME=admin
DJANGO_SUPERUSER_EMAIL=admin@gmail.com
DJANGO_SUPERUSER_PASSWORD=admin123
```

!!! danger "Production"
    Always change default credentials in production!

## Global Configuration

One Click DRF stores user preferences in `~/.config/one-click-drf/config.toml`.

```toml
[user]
github_username = "your-username"
dockerhub_username = "your-dockerhub"
```

This configuration is used when generating new projects.

## Docker Configuration

### Development

Use `docker-compose.dev.yml` for local development:

```bash
docker compose -f docker-compose.dev.yml up
```

### Production

Use `docker-compose.prod.yml` for production:

```bash
docker compose -f docker-compose.prod.yml up -d
```

## CI/CD Configuration

GitHub Actions workflows are in `.github/workflows/pipeline.yml`.

Configure secrets in your GitHub repository:
- `DOCKER_USERNAME`
- `DOCKER_PASSWORD`
- `AWS_ACCESS_KEY_ID`
- `AWS_SECRET_ACCESS_KEY`

## Infrastructure Configuration

Terraform variables are in `infra/terraform/variables.tf`.

Edit these before deploying:
- AWS region
- Instance types
- VPC configuration
