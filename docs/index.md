# One Click DRF

**One Click DRF** is a powerful CLI tool designed to bootstrap **production-ready** Django REST Framework projects in seconds.

[![PyPI version](https://img.shields.io/pypi/v/one-click-drf)](https://pypi.org/project/one-click-drf/)
[![Python versions](https://img.shields.io/pypi/pyversions/one-click-drf)](https://pypi.org/project/one-click-drf/)
[![License](https://img.shields.io/github/license/shemanto27/One-Click-Production-Ready-Django-Backend-Setup)](https://github.com/shemanto27/One-Click-Production-Ready-Django-Backend-Setup/blob/main/LICENSE)

## Why One Click DRF?

Stop copy-pasting code from old projects. Start with a solid foundation.

Every time a new project starts, developers face repetitive tasks:
- Manually installing packages
- Configuring settings and environment variables
- Setting up Docker, CI/CD, and infrastructure
- Forgetting critical configurations

**One Click DRF** automates all of this in seconds.

## Features

- 🐳 **Docker Ready** - Multi-stage Dockerfile and docker-compose
- ⚙️ **CI/CD** - Pre-configured GitHub Actions workflows
- 🏗️ **Infrastructure as Code** - Terraform templates for AWS
- ☁️ **AWS Deployment Ready** - Built-in cloud configurations
- 📊 **Monitoring** - Integrated Prometheus and Grafana
- 🛠️ **Production Settings** - Professional settings split and .env
- 📝 **Swagger API** - Instant API documentation with drf-yasg
- 📂 **Clean Architecture** - Organized apps folder structure
- 🔒 **Standard .gitignore** - Pre-configured Python .gitignore
- 🚀 **GitHub Integration** - Auto-initialize and push to GitHub

## Quick Start

Install the CLI tool:

```bash
uv tool install one-click-drf
```

Create a new project:

```bash
ocd init myproject --all
```

That's it! You have a production-ready Django REST Framework project.
