# One Click DRF (OCD) 🚀

**One Click DRF** হলো একটি শক্তিশালী CLI টুল যা দিয়ে আপনি মুহূর্তের মধ্যে **প্রোডাকশন-রেডি** Django REST Framework প্রোজেক্ট তৈরি করতে পারবেন।

পুরানো প্রোজেক্ট থেকে কোড কপি-পেস্ট করা বন্ধ করুন। একটি মজবুত ভিত্তি দিয়ে শুরু করুন।

## 🌟 কেন এই টুল?

অধিকাংশ Django টিউটোরিয়ালে সাধারণ স্ট্রাকচার শেখানো হয়। কিন্তু প্রোডাকশনে কাজ করার জন্য আপনার প্রয়োজন:
- সেটিংস ফাইলগুলোকে `base`, `dev`, `prod`-এ ভাগ করা।
- Docker এবং Docker Compose সেটআপ।
- CI/CD পাইপলাইন (স্বয়ংক্রিয় টেস্টিং)।
- Infrastructure as Code (Terraform)।
- Observability (Prometheus/Grafana)।

**ocd** আপনাকে একটি মাত্র কমান্ডের মাধ্যমে এই সবকিছু সেটআপ করে দেয়।

## 📦 ইন্সটলেশন (Installation)

```bash
pip install one-click-drf
```

## 🚀 ব্যবহারবিধি (Usage)

### নতুন প্রোজেক্ট তৈরি করা

```bash
ocd init myproject
```
এটি `myproject` নামে একটি ফোল্ডার তৈরি করবে এবং তার ভেতর প্রয়োজনীয় সব ফাইল সাজিয়ে দেবে।

### বর্তমান ফোল্ডারে প্রোজেক্ট তৈরি করা

```bash
ocd init .
```

### অতিরিক্ত ফিচার যোগ করা

আপনি চাইলে ফ্ল্যাগ (Flag) ব্যবহার করে বিভিন্ন ফিচার যোগ করতে পারেন:

```bash
ocd init myproject --docker --ci-cd
```

অথবা সবকিছু একসাথে পেতে:

```bash
ocd init myproject --all
```

## 🚩 CLI Flags

নিচের ফ্ল্যাগগুলো ব্যবহার করে আপনি প্রোজেক্ট কাস্টমাইজ করতে পারেন:

| ফ্ল্যাগ | বিবরণ |
|------|-------------|
| `--docker` | `Dockerfile` এবং `docker-compose.yml` যোগ করে |
| `--ci-cd` | GitHub Actions ওয়ার্কফ্লো যোগ করে (অটোমেটিক টেস্টিংয়ের জন্য) |
| `--iac` | AWS-এর জন্য Terraform স্লেটন তৈরি করে |
| `--observability` | Prometheus কনফিগারেশন যোগ করে |
| `--all` | ওপরের সব ফিচার একসাথে চালু করে |

## 📂 প্রোজেক্ট স্ট্রাকচার

আমরা একটি পরিষ্কার এবং মডুলার ফোল্ডার স্ট্রাকচার অনুসরণ করি:

```
project-root/
├── core/                 # প্রোজেক্ট কনফিগারেশন
│   ├── settings/         # সেটিংস ফাইল ভাগ করা থাকে
│   │   ├── base.py       # কমন সেটিংস
│   │   ├── dev.py        # ডেভেলপমেন্ট সেটিংস
│   │   ├── prod.py       # প্রোডাকশন সেটিংস
│   ├── urls.py
│   ├── wsgi.py
│   └── asgi.py
├── apps/                 # আপনার তৈরি করা অ্যাপগুলো এখানে থাকবে
├── requirements/         # লাইব্রেরি ডিপেন্ডেন্সি ফাইল
│   ├── base.txt
│   ├── dev.txt
│   └── prod.txt
├── manage.py
└── .env                  # এনভায়রনমেন্ট ভেরিয়েবল (লুকানো তথ্য)
```

**কেন `core/` আলাদা?**
সেটিংস এবং কনফিগারেশনকে আপনার মূল বিজনেস লজিক (`apps/`) থেকে আলাদা রাখলে প্রোজেক্ট পরিষ্কার থাকে এবং বুঝতে সুবিধা হয়।

## ⚙️ কনফিগারেশন

প্রথমবার চালানোর সময়, `ocd` আপনার গিটহাব এবং ডকারহাব ইউজার নেম জানতে চাইবে। এগুলো স্বয়ংক্রিয়ভাবে `~/.config/one-click-drf/config.toml` ফাইলে সেভ হয়ে থাকবে, যাতে বারবার টাইপ করতে না হয়।
